## Задание 1: Условные конструкции и функция date()

Используя функцию `date()`, формируется расписание на основе текущего дня недели:
- **John Styles**: работает в понедельник, среду и пятницу (с 8:00 до 12:00). В остальные дни — «Нерабочий день».
- **Jane Doe**: работает во вторник, четверг и субботу (с 12:00 до 16:00). В остальные дни — «Нерабочий день».

Для определения дня недели использован формат `date('N')` (где 1 — понедельник, 7 — воскресенье):

```php
$dayOfWeek = (int)date('N');

// График для John Styles
if ($dayOfWeek === 1 || $dayOfWeek === 3 || $dayOfWeek === 5) {
    $johnSchedule = "8:00-12:00";
} else {
    $johnSchedule = "Нерабочий день";
}

// График для Jane Doe
if ($dayOfWeek === 2 || $dayOfWeek === 4 || $dayOfWeek === 6) {
    $janeSchedule = "12:00-16:00";
} else {
    $janeSchedule = "Нерабочий день";
}
```

Таблица выводится в HTML:

```html
<table>
    <thead>
        <tr>
            <th>№</th>
            <th>Фамилия Имя</th>
            <th>График работы</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>1</td>
            <td>John Styles</td>
            <td><?= $johnSchedule ?></td>
        </tr>
        <tr>
            <td>2</td>
            <td>Jane Doe</td>
            <td><?= $janeSchedule ?></td>
        </tr>
    </tbody>
</table>
```

## Задание 2: Циклы

### 1. Цикл `for` с выводом промежуточных значений:

```php
$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br />";
}

echo "End of the loop: a = $a, b = $b";
```

### 2. Реализация через цикл `while`:

```php
$a = 0;
$b = 0;
$i = 0;

while ($i <= 5) {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br />";
    $i++;
}

echo "End of the loop: a = $a, b = $b";
```

### 3. Реализация через цикл `do-while`:

```php
$a = 0;
$b = 0;
$i = 0;

do {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br />";
    $i++;
} while ($i <= 5);

echo "End of the loop: a = $a, b = $b";
```

## Контрольные вопросы

### 1. В чем разница между циклами for, while и do-while? В каких случаях лучше использовать каждый из них?
- **`for`**: цикл со счетчиком и предусловием. Удобен, когда количество итераций известно заранее (например, проход по диапазону чисел от 0 до $N$). В круглых скобках сразу задаются инициализация счетчика, условие завершения и шаг изменения.
- **`while`**: цикл с предусловием. Проверяет условие *перед* каждой итерацией. Если условие изначально ложно (`false`), тело цикла не выполнится ни разу. Лучше использовать, когда число повторений заранее неизвестно и зависит от наступления некоторого события (чтение данных из потока/файла, пока не встретится EOF).
- **`do-while`**: цикл с постусловием. Сначала выполняет тело цикла, и только *после этого* проверяет условие. Гарантирует хотя бы одно выполнение тела цикла. Удобен в сценариях вида «запросить/сгенерировать данные и проверить их корректность; если некорректно — повторить».

### 2. Как работает тернарный оператор `? :` в PHP?
Тернарный оператор — это сокращенная форма условной конструкции `if-else`. Синтаксис:
```php
условие ? выражение_если_true : выражение_если_false;
```
Сначала вычисляется `условие`. Если оно истинно (`true`), возвращается результат первого выражения (после `?`). Если ложно (`false`), возвращается результат второго выражения (после `:`).
Пример:
```php
$status = ($dayOfWeek == 1) ? "Рабочий день" : "Нерабочий день";
```

### 3. Что произойдет, если в do-while поставить условие, которое изначально ложно?
Тело цикла **выполнится ровно один раз**. Так как проверка условия в `do-while` стоит в самом конце (постусловие), программа сначала выполняет инструкции внутри блока `{ ... }`, затем проверяет условие, убеждается, что оно ложно (`false`), и выходит из цикла.
